✓ Mobile npm install tamamladınız

📋 YAPMANIZ GEREKENLER (3 ADIM)
────────────────────────────────────────────────────────────────

1️⃣  BACKEND DEPENDENCIES YÜKLE
   
   PowerShell'de:
   cd backend
   npm install

   ⏱️  Süre: 2-3 dakika


2️⃣  BACKEND'İ BAŞLAT

   npm run dev

   ✅ Başarılı ise göreceksiniz:
   ✅ Database initialized
   ✅ Data sync started
   🚀 Server running on http://localhost:3000


3️⃣  MOBILE'I BAŞLAT (Yeni terminal)

   cd mobile
   npm start
   
   Sonra: 'w' tuşuna bas (web'de açılır)
