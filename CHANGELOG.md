# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-12-04

### Added
- Initial release of TEFAS Tracker
- Backend API with Express.js and SQLite
- React Native Expo mobile app (Web + Android)
- Fund information with multiple timeframe returns
- Portfolio management system
- Favorites functionality
- Live intraday return estimates
- Automatic data sync from TEFAS API
- Comprehensive documentation
- Docker support
- CI/CD with GitHub Actions
- Development scripts and utilities

### Features
- 📊 Browse all TEFAS funds with search and filter
- 💼 Create and manage multiple portfolios
- ⭐ Save favorite funds for quick access
- 📈 View live estimated intraday returns
- 📱 Cross-platform support (web and Android)
- 🔄 Automatic daily data updates
- 📊 Price history and charts
- 💰 Profit/loss tracking
- 🎨 Modern, responsive UI

### Technical
- TypeScript throughout
- SQLite database with better-sqlite3
- React Query for state management
- React Navigation for routing
- Axios for API calls
- Node-cron for scheduling
- Helmet for security
- Morgan for logging
- Compression for performance

### Documentation
- README files in English and Turkish
- Quick start guide
- API documentation
- Feature documentation
- Setup guide
- Deployment guide
- Contributing guidelines
